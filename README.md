# first-pr-with-claude

A practice repository for opening my first pull request with Claude Code.

## What's here

This repo exists to get comfortable with the GitHub PR workflow:
create a branch, make a change, open a pull request, and merge it.

## Getting started

```bash
git clone https://github.com/ruslapro-lang/first-pr-with-claude.git
cd first-pr-with-claude
```
